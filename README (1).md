## 🛠️ Опис проєктів у розробці (Projects Overview)

### 📌 1. Мій перший проєкт: Анімований візуалізатор виконання коду (Visualgo-style IDE)
Інтерактивне середовище (IDE) для першокурсників, яке перетворює сухий текст програми на динамічну, анімовану карту пам'яті.
*   **Технології:** Python, PyQt6, `jedi` (інтелектуальний аналіз коду), `ast` (Abstract Syntax Trees).
*   **Ключові фічі:** 
    *   Покрокове виконання коду в окремому потоці (`QThread`).
    *   Кольорове підсвічування стану змінних у реальному часі (новий, змінений або стабільний стан комірки).
    *   Можливість встановлення точок зупину (breakpoints) кліком миші на панелі номерів рядків.
*   **Статус:** 🧪 Прототипування / реалізація покрокового дебагера.

---

### 📌 2. Мій другий проєкт: Покроковий візуалізатор масивів та векторів C++
Дидактичний інструмент, створений для наочного пояснення роботи з динамічною пам'яттю та STL-векторами у C++.
*   **Технології:** Python, PyQt5, Regular Expressions (`re`).
*   **Ключові фічі:**
    *   Парсинг коду ініціалізації та інструкцій присвоєння типу `A[idx] = val;` безпосередньо з текстового поля.
    *   Плавне покрокове промальовування елементів у вигляді красивої графічної **"драбинки"**.
    *   **Панель історії операцій:** детальний кольоровий лог дій під пунктирним роздільником (зелений — *«Додано»*, червоний — *«Зміна / Видалено»*), що зберігає повну хронологію без затирання основної сцени.
*   **Статус:** ⚙️ Активна розробка та виправлення багів (оптимізація шрифтів, робота з від'ємними числами).

---

### 📌 3. Мій третій проєкт: Інтерактивна консоль Prolog
Вебсервіс у стилі Jupyter Notebook для швидкого тестування логічних запитів та декларативного програмування.
*   **Технології:** Flask, Prolog (`library(clpfd)`), `PrologMQI` (swiplserver), Tailwind CSS.
*   **Ключові фічі:**
    *   Двопанельний інтерфейс: ліва сторона — редактор бази знань (правила, факти); права сторона — результати логічного виведення.
    *   Інтегровані складні комбінаторні задачі (наприклад, задача про N ферзів `queens(N, Qs)`).
    *   Миттєвий зворотний зв'язок із колірним оформленням вердиктів: зелений блок для *«True (Yes)»*, жовтий — для *«False (No)»*.
*   **Статус:** 🔍 Тестування алгоритмічної частини замовником (`@yurarud`).
