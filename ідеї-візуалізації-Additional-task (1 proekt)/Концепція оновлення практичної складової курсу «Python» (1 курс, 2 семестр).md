# Пропозиції щодо розширення практичного змісту курсу «Програмування мовою Python 1 курс» 

Цей документ містить огляд прикладних тем та інженерних практик, інтеграція яких у лабораторний практикум другого семестру дозволить сформувати у здобувачів базу для подальшої науково-дослідної роботи, аналізу даних і промислової розробки.

---

### 1. Наукові обчислення та аналіз даних
Формування фундаменту для моделювання, обчислювальних методів та роботи з реальними датасетами.

* **NumPy:**
  * Створення та маніпуляція багатовимірними масивами (`ndarray`), векторні операції, зрізи, робота з числовими діапазонами.
  * Базові матричні операції (лінійна алгебра) як швидка альтернатива вкладеним циклам.
* **Matplotlib / Seaborn:**
  * Візуалізація залежностей: побудова 2D-графіків функцій, гістограм розподілу, розсіювання даних.
  * Формування культури графічного представлення експериментальних результатів (підписи осей, сітка, масштабування).
* **Pandas:**
  * Структури `Series` та `DataFrame`.
  * Базові операції фільтрації, групування, агрегації та первинного статистичного аналізу табличних даних.

---

### 2. Серіалізація, структуровані дані та збереження стану
Перехід від консольних скриптів до застосунків, які зберігають стан і працюють із зовнішніми джерелами даних.

* **Формати обміну даними (JSON, CSV, XML):**
  * Читання, парсинг і серіалізація структур.
  * Практика збереження користувацьких налаштувань, логів або експорту звітів.
* **Реляційні бази даних (модуль `sqlite3`):**
  * Робота з локальною СУБД SQLite без потреби розгортання окремого сервера.
  * Складання базових SQL-запитів (`CRUD`), транзакційність, параметризовані запити для уникнення SQL-ін'єкцій.

---

### 3. Інженерна культура, архітектура та DevTools
Формування професійних стандартів розробки з першого року навчання.

* **Контроль версій (Git / GitHub):**
  * Базовий воркфлоу: фіксація змін, створення гілок (`branches`), оформлення пул-реквестів (`PR`), вирішення конфліктів.
  * Формування змістовної історії комітів за загальноприйнятими стандартами.
* **Стандарти оформлення коду (PEP 8):**
  * Дотримання конвенцій іменування та структури модулів.
  * Використання лінтерів (`flake8`, `black`) як інструменту самоконтролю.
* **Статична типізація (`typing`):**
  * Базові тайп-хінти для сигнатур функцій і параметрів.
  * Розуміння переваг типізації для читабельності коду та раннього виявлення помилок.

---

### 4. Основи мережевої взаємодії
Демонстрація того, як Python взаємодіє із зовнішніми сервісами та протоколами.

* **Мережеві сокети (`socket`):**
  * Розуміння моделі «клієнт-сервер», передача байтових потоків через TCP.
* **Протокол HTTP (модуль `urllib` або бібліотека `requests`):**
  * Виконання базових `GET`/`POST`-запитів.
  * Робота з відкритими REST API (отримання публічних даних у форматі JSON).
