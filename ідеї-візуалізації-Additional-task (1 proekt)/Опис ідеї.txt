# Концепція візуалізації: Відображення структури словника (Key-Value Mapping)

## 1. Суть ідеї
Графічне представлення словника (dict / hash map) у вигляді двох взаємопов'язаних множин: незмінних унікальних ключів та відповідних їм значень зі стрілками-покажчиками зв'язку.

## 2. Мета
Наочно показати студентам принципи:
* Одностороннього відображення ($key \to value$).
* Вимоги незмінності (immutability) ключів.
* Можливості дублювання значень при унікальності ключів.

## 3. Графічні елементи
* **Лівий блок (множина ключів):** овал/контейнер з елементами незмінного типу (рядки, числа).
* **Правий блок (множина значень):** контейнер із довільними об'єктами.
* **Зв'язки:** спрямовані стрілки від конкретного ключа до його значення.
* **Спільна рамка:** контур об'єкта із зазначенням назви змінної (наприклад, `eng2sp`).

## 4. Потенційні сценарії використання
* Ілюстрація для конспекту або методички.
* Прототип для інтерактивного візуалізатора на базі PyQt / графічного рушія.
