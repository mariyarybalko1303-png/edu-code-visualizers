# 🎓 Екосистема планування та моніторингу навчального розкладу (Django + CSP)

Сучасна дворівнева веб-система для автоматизованого складання, ручного диспетчерського коригування та публічного перегляду розкладу занять університету.

Архітектура поєднує математичний рушій вирішення задач задоволення обмежень (**CSP — Constraint Satisfaction Problem**) з адаптованими UX-патернами відкритих розкладів провідних українських вишів (Запорізька політехніка `portal.zp.edu.ua`, СНАУ `portal.snau.edu.ua`).

## 📌 Ключові можливості

### 1. ⚙️ Диспетчерська панель кафедри

* **CSP-генерація без колізій**: Автоматичний розподіл занять з гарантією відсутності накладок викладачів, аудиторій та академічних груп.

* **Підтримка потокових лекцій**: Об'єднання кількох академічних груп на спільні потоки з оптимізацією аудиторного фонду.

* **Гнучке врахування зайнятості**: Індивідуальні графіки недоступності викладачів (окремі пари або повні дні) з можливістю оперативного редагування `✎` та скасування `✕`.

* **Ручне коригування сітки**: Швидке додавання або видалення окремих пар безпосередньо з інтерактивної таблиці.

* **Двотижнева циклічність**: Чіткий поділ розкладу на Чисельник (1 тиждень — червоний акцент) та Знаменник (2 тиждень — зелений акцент).

* **Академічні обмеження**: Вбудовані бізнес-правила (зокрема ліміт понеділка на 7 пар із блокуванням 8-ї пари).

* **Експорт в Excel (`.xlsx`)**: Автоматичне форматування з переносом рядків, індивідуальними висотами комірок та акцентним відображенням груп.

* **Пакетний імпорт**: Завантаження вихідних даних із файлів `.xlsx` та `.csv`.

### 2. 👥 Бази даних студентів та викладацького складу

* **Реєстр студентів (`/students/`)**:

  * Облік ПІБ, факультету, курсу (1–5) та академічної групи.

  * Миттєва "жива" фільтрація без перезавантаження сторінки.

  * Динамічна наскрізна автонумерація списку (`№ 1, 2, 3...`).

  * Перехід в особисту картку академічної успішності та розкладу в один клік.

* **Реєстр викладачів (`/teachers/`)**:

  * Облік кафедр, ПІБ та контактних аудиторій/номерів.

  * Швидкий предикативний пошук і фільтрація за кафедрами.

### 3. 🌐 Публічний клієнтський портал

Розділ для викладачів і студентів, який не потребує входу в панель адміністрування:

* **Студентський модуль (`/time-table/student/`)**:

  * Каскадна панель фільтрів: **Факультет ➔ Курс (1–5) ➔ Група ➔ Студент**.

  * Динамічне підтягування списків через API без оновлення сторінки.

  * Відображення розкладу як для цілої групи, так і персоналізовано для студента.

* **Викладацький модуль (`/time-table/teacher/`)**:

  * Швидка вибірка: **Кафедра ➔ Викладач**.

  * Персональний графік занять на тиждень із зазначенням предметів, аудиторій та закріплених груп.

* **Особиста картка студента (`/students/<id>/schedule/`)**:

  * Детальний реєстр дисциплін поточного семестру та щотижневе навантаження.

## 🛠️ Стек технологій

* **Backend**: Python 3.10+, Django 6.x

* **Алгоритмічний рушій**: Custom CSP Backtracking Solver with MRV & Degree heuristics

* **Frontend**: HTML5, CSS3, Vanilla JavaScript (асинхронні запити Fetch API, жива фільтрація DOM)

* **Робота з електронними таблицями**: `openpyxl`

* **База даних**: SQLite (для локального тестування) / PostgreSQL ready

## 🚀 Інструкція із запуску проєкту

### 1. Клонування репозиторію

```
git clone https://github.com/mariyarybalot1303-png/edu-code-visualizers.git
cd edu-code-visualizers

```

### 2. Створення та активація віртуального середовища (опціонально)

```
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

```

### 3. Встановлення залежностей

```
pip install django openpyxl

```

### 4. Застосування міграцій

```
python manage.py migrate

```

### 5. Запуск локального сервера

```
python manage.py runserver

```

## 📍 Карта маршрутів (URL Endpoints)

* `http://127.0.0.1:8000/` — Головна диспетчерська панель розкладу (генератор CSP, довідники, ручне призначення).

* `http://127.0.0.1:8000/time-table/student/` — Публічний портал перегляду розкладу студентів.

* `http://127.0.0.1:8000/time-table/teacher/` — Публічний портал перегляду розкладу викладачів.

* `http://127.0.0.1:8000/students/` — База даних студентів з інтерактивними фільтрами.

* `http://127.0.0.1:8000/students/<id>/schedule/` — Особиста картка студента (семестрове навантаження).

* `http://127.0.0.1:8000/teachers/` — База даних викладачів кафедри.

* `http://127.0.0.1:8000/export/?week=1` — Генерація та завантаження розкладу в Excel.

* `http://127.0.0.1:8000/import/` — Сторінка пакетного імпорту файлів розкладу (`.xlsx`, `.csv`).
