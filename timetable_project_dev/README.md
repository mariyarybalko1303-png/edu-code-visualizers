# 📅 University Timetable & CSP Scheduler System (`timetable_project_dev`)

> **Гібридна університетська система управління розкладом занять з використанням Python/Django та логічного програмування (SWI-Prolog / CLP(FD)).**

---

## 📌 Опис проєкту та Архітектура

Система призначена для автоматизації складання, перевірки та управління університетським розкладом для здобувачів вищої освіти усіх трьох рівнів: **Бакалаврату, Магістратури та Аспірантури**.

Проєкт побудований за **гібридною архітектурою**:
1. **Веб-оболонка та Бекенд (Python / Django):** Відповідає за веб-інтерфейс, роботу з реляційною базою даних SQLite, обробку таблиць Excel (`.xlsx`, `.xls`) та експорт звітів.
2. **Інтеграційний міст (`solver.py`):** Забезпечує зв'язок між середовищами Python (Django ORM) та SWI-Prolog.
3. **Логічний рушій (SWI-Prolog + CLP(FD)):** Інтелектуальне ядро системи для розв'язання задач із задоволенням обмежень (Constraint Satisfaction Problem — CSP). Гарантує відсутність колізій (перетинів за часом для викладачів, аудиторій, академічних груп та потокових занять).

---

## 🛠️ Технологічний Стек

* **Бекенд:** Python 3.10+, Django 6.1
* **Логічний рушій:** SWI-Prolog (бібліотека обмежень скінченних доменів `clpfd`)
* **Інтеграційний шар:** Python-Prolog Adapter (`solver.py` / `prolog_solver.pl` / `timetable.pl`)
* **Обробка даних:** `openpyxl`, `xlrd`
* **Фронтенд:** HTML5, CSS3, адаптивні табличні сітки

---

## 📱 Основні Модулі та Функціонал

* **Головна панель розкладу (`/`):** Інтерактивна сітка на 1-й та 2-й тижні з фільтрацією за групами (збереження вибору в сесії), миттєве редагування/видалення занять, 4 панелі керування (довідники, ручне редагування, облік зайнятості, налаштування CSP).
* **Імпорт даних (`/import/`):** Динамічний завантажувач Excel-структур із розпізнаванням днів тижня, пар, тижнів та спеціальностей аспірантів.
* **Публічні портали (`/time-table/student/`, `/time-table/teacher/`):** Персональні кабінети з каскадними фільтрами (*Факультет ➔ Курс ➔ Група ➔ Студент / Кафедра ➔ Викладач*) та завантаженням персонального розкладу в Excel.
* **Каталог вибіркових компонентів (ОК / ВК):**
  * Бакалаврат (`/time-table/selective/bachelor/`)
  * Магістратура (`/time-table/selective/master/`)
  * Аспірантура (`/time-table/selective/postgraduate/`)
  * Управління списками студентів, записаних на вибіркові дисципліни.
* **Автоматичний генератор розкладу (CSP + Prolog):** Передача вимог до навантаження в Prolog-модуль, математична перевірка комбінацій через `clpfd` та розстановка занять без колізій у базу даних Django.

## 🚀 Інструкція з Встановлення та Запуску

```powershell
# 1. Клонувати репозиторій та перейти в папку проєкту:
cd C:\path\to\timetable_project_dev

# 2. Створити та активувати віртуальне середовище:
python -m venv venv
.\venv\Scripts\Activate.ps1

# 3. Встановити залежності:
pip install django openpyxl xlrd

# 4. Виконати міграції бази даних:
python manage.py makemigrations scheduler
python manage.py migrate

# 5. Запустити сервер розробки:
python manage.py runserver
```

**Доступ у браузері:** `http://127.0.0.1:8000/`
